# 선언문

근거: 2026-09-13 사용자 대화에서 정한 공개 준비 범위다. 구현 완료 상태를 뜻하지 않는다.

[BA-001]
Browser Assistant의 첫 공개 준비는 자체 운영 버전을 대상으로 한다.

[BA-002]
자체 운영 버전은 코드스텝이 운영하는 Browser Assistant 서버 없이 실행할 수 있어야 한다.

[BA-003]
사용자는 Browser Assistant를 코드스텝 팀의 공개 저장소로 배포할 계획이다.

[BA-004]
첫 공개 준비 범위에는 설치 방법, 사용 방법, 프롬프트 작성 팁, 언어 설정 안내가 포함된다.

[BA-005]
현재 정리 단계에서 관리형 서비스의 서비스 API 키 발급과 과금 기능은 구현 범위에 포함하지 않는다.

[BA-006]
첫 공개 준비 범위에는 한국어·영어 사용법과 튜토리얼 문서 및 실행 예시 영상이 포함된다.

[BA-007]
사용자는 첫 공개 준비 결과의 저장소 생성·커밋·푸시를 요청했다.
