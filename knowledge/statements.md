# 선언문

근거: 2026-09-13 사용자 대화에서 정한 공개 준비 범위다. 구현 완료 상태를 뜻하지 않는다.

[BA-001]
Browser Assistant의 첫 공개 준비는 자체 운영 버전을 대상으로 한다.

[BA-002]
자체 운영 버전은 코드스텝이 운영하는 Browser Assistant 서버 없이 실행할 수 있어야 한다.

[BA-003]
사용자는 Browser Assistant를 코드스텝 팀의 공개 저장소로 배포할 계획이다.

[BA-004]
첫 공개 준비 범위에는 설치 방법, 사용 방법, 프롬프트 작성 팁, 언어 설정 안내가 포함된다.

[BA-005]
현재 정리 단계에서 관리형 서비스의 서비스 API 키 발급과 과금 기능은 구현 범위에 포함하지 않는다.

[BA-006]
첫 공개 준비 범위에는 한국어·영어 사용법과 튜토리얼 문서 및 실행 예시 영상이 포함된다.

[BA-007]
사용자는 첫 공개 준비 결과의 저장소 생성·커밋·푸시를 요청했다.

[BA-008]
2026-09-13에 코드스텝 팀의 공개 저장소 `https://github.com/codestepteam/browser-assistant`를 생성했다.

근거: 2026-09-15 사용자가 GPT-Live 전환 대화에서 요청한 입력 및 종료 정책이다.

[BA-009]
Browser Assistant의 GPT-Live 음성 입력은 누르고 말하기 방식을 사용한다.

[BA-010]
사용자가 버튼을 놓으면 Browser Assistant는 마이크 입력을 즉시 차단한다.

[BA-011]
Browser Assistant는 일정 시간 사용하지 않은 음성 세션을 종료한다.

[BA-012]
2026-09-15 사용자 요청에 따라 GPT-Live의 작업 판단 모델과 같은 설정을 공유하는 글·도구 모델의 기본값은 `gpt-5.6-luna`이다.

[BA-013]
채팅창은 기본적으로 음성 세션을 시작할 때 표시하며 대기 중에는 마이크 아이콘만 표시한다. 설치자는 `chatVisibility="always"`로 항상 표시하도록 변경할 수 있다. 실행 확인과 연결 오류는 숨기지 않는다.

[BA-014]
마이크 버튼은 페이지의 모달·선택 팝업이 열려도 화면 오른쪽 아래의 최상위 레이어에 유지한다.

BA-013~BA-014 근거: 2026-09-16 Dream Catchers 화면 피드백에서 사용자가 공통 Browser Assistant의 기본 표시 정책과 설정 인자를 지정했다.

[BA-015]
기본 실행 확인 여부는 AI가 사용자 요청과 현재 화면에서 관찰한 조작의 영향을 근거로 판단한다.

[BA-016]
사이트의 `data-agent-action="confirm"`과 `screen.requiresConfirmation`이 반환한 `true`는 AI 판단과 무관하게 사용자 확인을 강제한다.

[BA-017]
Browser Assistant는 `safe` 또는 `preview` 표시로 실행 확인을 생략하는 설정을 제공하지 않는다.

[BA-018]
AI가 실행 확인을 요청하거나 사이트가 확인을 강제한 경우 실제 사용자가 확인해야 조작을 실행한다.

BA-015~BA-018 근거: 2026-09-17 사용자가 기본 확인 판단을 AI에 맡기고 confirm 설정만 유지하도록 요청했다.

[BA-019]
사용자는 2026-09-17에 Browser Assistant의 npm 공개 게시와 main 푸시 후 자동 업데이트를 요청했다.
